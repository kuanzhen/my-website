## Why

当前站点仍是 Vite 脚手架生成的占位页面（一张带计数器按钮的演示卡片），没有任何个人品牌信息，无法对外展示。Hero Section 是访客进入站点看到的第一屏，需要在这一屏内完成"我是谁"的表达，并同时建立全站可用的亮/暗主题机制——后续所有区块都要依赖这套机制，因此必须先行落地。

## What Changes

- 新增全屏高度（`min-h-dvh`）的 Hero Section，垂直+水平居中展示三组内容：姓名（页面唯一的 `h1`）、职业、一句话自我介绍。
- 新增背景层，由两层叠加构成：底层为 CSS 渐变（`radial-gradient` 色块，主题变量驱动的亮/暗配色），上层为 Canvas 粒子（`pointer-events-none`、`aria-hidden="true"`）。
- 粒子层允许的唯一动效是**粒子缓慢漂移**；不做任何其他动画。
- 粒子层必须优雅降级：`prefers-reduced-motion` 时静止，Canvas 不可用或脚本失败时仅剩 CSS 渐变。
- 新增全站亮/暗主题机制：默认跟随系统偏好，用户可显式切换，显式选择持久化并在刷新后保留；切换即时生效且不出现首屏闪烁（FOUC）。
- 新增主题切换控件（`ThemeToggle`），本次放置在 Hero 内部。
- 姓名字段使用系统楷体字族（不加载任何字体文件），**只作用于姓名这一处**，不改变正文与其他文字的字体。
- 姓名以繁体呈现为「寬真居士」（职业与介绍保持简体），字号同步上调以承担首屏视觉重量。
- 新增 CTA 按钮「我的项目」，位于介绍下方，指向站外链接；链接地址由站点主人提供，未提供期间不渲染可点击的死链。
- 移除脚手架占位内容（计数器卡片），以及未被任何文件引用的模板资源（`src/App.css`、`src/assets/react.svg`、`src/assets/vite.svg`）。

## Capabilities

### New Capabilities

- `hero-section`: 首屏 Hero 的内容结构、全屏高度与居中布局、渐变+粒子背景的分层与降级行为、可访问性要求。
- `theme-switching`: 全站的亮/暗主题解析优先级、持久化、切换生效时机、防首屏闪烁，以及背景层（含 Canvas 粒子）跟随主题变化的行为。

### Modified Capabilities

无。`openspec/specs/` 当前为空，本次是首个变更，不涉及对既有规范的行为修改。

## Impact

**受影响的现有代码**

- `src/App.tsx`：现有内容为脚手架演示卡片，将被 Hero 替换，原有内容整体移除。
- `src/index.css`：新增 Tailwind v4 的 `@custom-variant dark` 声明与主题色 token（`--color-*` / 粒子色），属全局样式改动；另新增一个姓名字族 token（系统楷体栈）。
- `index.html`：`<head>` 内需插入阻塞式 inline script 用于首屏主题判定，避免 FOUC；同时补充 `color-scheme` 与 `theme-color` 元信息。
- 删除未被引用的 `src/App.css`、`src/assets/react.svg`、`src/assets/vite.svg`。已确认 `src/assets/hero.png` 同样未被引用，但保留该文件（可能为后续视觉资源）。

**影响评估**

- 无新增 npm 依赖、无新增字体资源：粒子层手写 Canvas 2D，不引入 `tsparticles` 等库；姓名使用系统楷体，不加载任何字体文件，首屏预算不受字体影响。
- 主题机制是全局能力，会影响后续所有区块的样式写法（组件需同时考虑 `dark:` 变体）；本次只交付机制与 Hero 内的切换控件，不交付导航栏位置。
- 性能风险点：Canvas 像素比与粒子数量需设上限；粒子层应在首屏绘制完成后延迟启动，避免挤占 LCP。
- 可访问性风险点：亮色模式下文字压浅色渐变可能对比度不足，需在内容层与背景层之间加遮罩并实测对比度。
- 本次不涉及任何图片渲染，因此 CLAUDE.md 中的 lazy loading 规则无适用对象。
- 部署相关：`vite.config.ts` 尚未配置 `base: '/my-website/'`，不在本次范围内，但会导致 GitHub Pages 部署后资源 404，需后续单独处理。

**out-of-scope（严禁开发）**

- 不做动画效果：不做入场动画、不做滚动触发动画、不做平滑滚动、不做渐变色块流动。唯一允许的是粒子缓慢漂移。
- 不做导航栏，也不做吸顶/固定头部。
- 不做后端 API，不引入任何网络请求或数据获取。
- 不做站内 projects 区块：CTA 只负责跳到站外链接，不在本站新增项目列表页面。
- 不做 Hero 以外的页面区块（projects / about / contact / blog）。
- 不做 GitHub Pages 部署配置与 `base` path 设置。
- 不做国际化。
- 不做全站字体替换：楷体字族只用于姓名，正文、职业、切换控件等一律沿用系统无衬线字体。
- 不引入字体选择/切换 UI，不做字体回退的可视化调试面板。
- 不接入自定义字体：不加载任何 webfont，不做字体子集化，不内嵌商业字库（含瘦金体、篆书字库）。
