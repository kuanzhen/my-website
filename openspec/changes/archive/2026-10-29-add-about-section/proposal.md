## Why

站点目前从 Hero 首屏直接进入项目展示，访客看不到站主本人的介绍，也无法理解「寬真居士」与「混血哲谈」之间的关系。新增「关于我」区域，让访客在浏览完项目与联系信息后，能停下来认识站主本人及其品牌。

## What Changes

- 在页面末尾（`#contact` 之后）新增「关于我」区域 `AboutSection`，占据 `#about` 锚点。
- 区域布局：左侧为站主照片，右侧为三段个人简介；照片与简介下方展示纯文本品牌标签「混血哲谈」。
- 照片使用 lazy loading，并预留固定宽高比避免加载时布局跳动；先用占位图，apply 后由站主替换为真实照片。
- 导航栏右侧新增「关于」链接，指向 `#about`；导航链接顺序变为「首页 / 项目 / 联系我 / 关于」，与页面实际顺序一致。
- 导航新增链接后，在 320px 窄屏下压缩间距与字号，保证品牌标识、四个链接与主题切换控件仍全部可见可用。
- 「关于」链接复用现有平滑滚动与 hash 同步机制，不新增第二套滚动实现。

## Capabilities

### New Capabilities

- `about-section`: 「关于我」区域的锚点、照片与三段简介的左右布局、品牌标签「混血哲谈」、响应式堆叠、图片懒加载与双主题可读性。

### Modified Capabilities

- `site-navigation`: 导航由三个页面内链接变为四个（新增「关于」→ `#about`）；页面锚点由三个变为四个；键盘焦点顺序与 320px 窄屏适配要求随之更新。

## Impact

**受影响的现有代码**

- `src/App.tsx`：在联系我占位 section 之后追加 `AboutSection`，传入照片与三段简介数据。
- `src/components/Navigation/NavBar.tsx`：`NAV_LINKS` 增加 `{ href: '#about', label: '关于' }`，并调整 320px 下的间距/字号。
- 新增 `src/components/sections/AboutSection.tsx` 与照片占位资源（`src/assets/about/`）。
- 简介文案与照片为占位内容，apply 阶段由站主替换；品牌标签文案固定为「混血哲谈」。

**影响评估**

- 无新增 npm 依赖、无路由变化，站点仍是单页 + 锚点。
- 平滑滚动：复用 `handleAnchorClick` 与 `scrollToHash`，`#about` 沿用 `scroll-mt-20`，标题不被固定导航遮挡。
- 主题机制：照片容器、正文与品牌标签使用现有 token 与 `dark:` 变体，不引入硬编码颜色。
- 首屏性能：关于我位于页面末尾，照片懒加载，不影响首屏 < 2 秒约束；Hero 粒子层与项目卡片不受影响。
- 导航窄屏：现有三链接在 320px 下已接近排满，新增第四个链接必须同步压缩间距与字号，否则会横向溢出（既有 `site-navigation` 规范要求不折叠、不隐藏）。
- 联系我占位 section 内容与位置不变，只是不再是页面最后一块。

**out-of-scope（严禁开发）**

- 不做联系我表单（用户明确排除）。
- 不做社交链接、技能条、时间线、履历下载等超出「照片 + 三段简介 + 品牌标签」的内容。
- 不新增「关于我」独立页面或路由，仍为单页锚点。
- 不改动项目展示区、Hero、主题切换机制与 `#contact` 占位内容。
- 不为关于我区域加入场动画、滚动触发动画或图片轮播。
